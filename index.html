Odoo 19 → 20: functional study changes

Independent study guide: connect existing Odoo lessons and quizzes to documented changes in Odoo 20. Not an official Odoo course or certification bank.

Saved 29 October 2026. Keep the Odoo 19 foundation and add a focused Odoo 20 differences pack. This review covers selected functional changes, not every feature or localization.

Read each row from existing Odoo lesson and quiz → version evidence → official Odoo 20 change → practice check. “Version not confirmed” means the recording still needs inspection. A source link does not mean Odoo has updated that video or quiz to 20. No Runbot exercises have been executed.

These changes are documented by Odoo; the practice exercises below are our proposed checks, not completed database tests. A feature listed on the 20 page is not automatically new in 20: entries marked available in earlier versions were excluded.
